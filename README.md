# my-vue-app

A Vue 2 application with an Express server. The frontend is in [`src/`](src/) and the server is in [`server/`](server/). The commands below describe the frontend; server dependencies are listed in [`server/package.json`](server/package.json).

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Lints and fixes files
```
npm run lint
```
